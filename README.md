# 🤖 JarvisMentor — Telegram AI Assistant Bot

Продвинутый Telegram-бот на базе Python, `pyTelegramBotAPI` и Groq API, созданный для разработки, код-ревью и архитектурных консультаций.

## 🔥 Ключевые особенности
- **Три уникальных характера:**
  - 🤝 **«Свой бро»** — дружеская поддержка и непринужденное общение.
  - 💻 **«Кодер»** — токсичный сеньор, который гоняет за чистоту кода и... умеет молча (или ворча) скидывать готовые `.py` файлы по запросу.
  - 🧠 **Эксперт** — холодный enterprise-архитектор, мыслящий бизнес-метриками и стандартами индустрии.
- **Умная доставка файлов:** Бот не спамит документами просто так, но если пользователь просит скинуть код файлом (через триггеры вроде *«скинь файлом»*, *«.py»*), код автоматически очищается из ответа и отправляется как готовый документ.
- **Отказоустойчивость сети:** Бесконечный цикл опроса с автопереподключением защищает бота от разрывов связи и тайм-аутов с серверами Telegram (`ReadTimeout`).
- **Защита от лимитов токенов (Groq TPM/OTPM):** Реализована оптимизация контекста (бот помнит последние 8 сообщений) и жесткое ограничение токенов генерации (`max_tokens`), предотвращающие перегрузку API.

## 🛠 Технологический стек
- **Python 3.10+**
- `pyTelegramBotAPI` (Telebot)
- Groq Cloud API (Qwen / Llama модели)
- Модульная архитектура (`main.py`, `handlers.py`, `ai_service.py`, `config.py`)
