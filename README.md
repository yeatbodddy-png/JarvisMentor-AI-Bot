# 🤖 JarvisMentor — Advanced AI Mentor & Telegram Bot

Продвинутый многофункциональный Telegram-бот на базе Python (`pyTelegramBotAPI`), Groq API, OpenAI Whisper и мультимодальных нейросетей. Создан для разработки, код-ревью, архитектурных консультаций и ежедневных инженерных задач.

## 🔥 Ключевые возможности и архитектура

### 🎭 Три уникальных характера (Persona Management)
- 🤝 **«Свой бро»** — дружеская поддержка, эмпатия и непринужденный разговор на любые темы. При отправке файлов общается тепло и по-дружески.
- 💻 **«Кодер»** — токсичный сеньор-наставник. Гоняет за чистоту кода, строго фокусит на IT и разработке, но ворча выполняет грязную работу.
- 🧠 **«Эксперт»** — холодный enterprise-архитектор. Мыслит бизнес-метриками, масштабируемостью, отказоустойчивостью и стандартами индустрии.

### 📁 Умная доставка файлов (Smart File Delivery)
- Автоматический парсинг и извлечение блоков кода (` ```python ... ``` `) из ответов нейросети.
- Поддержка мультиязычных триггеров (русский и английский: *«скинь файлом»*, *«.py»*, *«send as file»*).
- Динамические подписи к документам под каждый характер бота.

### 👁️ Мультимодальный анализ (Vision & Documents)
- **Скриншоты и изображения:** Анализ картинок с кодом, интерфейсами или ошибками через мультимодальные модели Groq (`ask_ai_with_vision`).
- **Документы:** Чтение и разбор файлов `.docx` и текстовых исходников на лету.

### 🎤 Голосовой ввод с автоопределением языка (OpenAI Whisper)
- Надиктовывай сообщения голосом как на **русском**, так и на **английском** языке.
- Интеграция с Whisper с автоматическим определением языка (Language Detection) без жестких ограничений.

### 🛡️ Отказоустойчивость и безопасность API
- **Сетевая защита:** Бесконечный цикл polling с автопереподключением (`while True`) защищает от тайм-аутов и разрывов соединения с Telegram API (`ReadTimeout`, `Conflict 409`).
- **Контроль лимитов Groq (TPM/OTPM):** Оптимизация истории диалога (хранение последних 8 сообщений) и жесткие ограничения генерации (`max_tokens=1000`), предотвращающие перегрузку токенов.
- **Автоматический выбор моделей:** Динамический сбор актуальных моделей Groq с приоритизацией лучших (Llama 70B/405B, Qwen, DeepSeek).

## 🛠 Технологический стек
- **Python 3.10+**
- `pyTelegramBotAPI` (Telebot)
- Groq Cloud API (Text & Vision)
- OpenAI Whisper API
- `python-docx` для обработки документов
- Модульная архитектура (`main.py`, `handlers.py`, `ai_service.py`, `config.py`, `utils.py`)
